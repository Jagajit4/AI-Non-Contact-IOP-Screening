💡 Project Overview & Problem Statement

Glaucoma is the leading cause of irreversible blindness globally. Traditional Intraocular Pressure (IOP) measurement tools (like Goldmann Applanation Tonometry or Air-Puff Tonometers) are prohibitively expensive ($3,000–$15,000+), require direct corneal contact, anesthesia drops, or high-pressure air bursts, making remote screening in rural or low-resource settings nearly impossible.

✨ Our Proposed Solution

An AI-driven, non-contact screening system that uses standard optical smartphone cameras to capture eye imagery, automatically segment pupil and iris boundaries, extract biometrics, and evaluate glaucoma risk using locally deployed machine learning models.

⭐ Novelty & Unique Selling Points (USP)

  • ✔ 100% Non-Contact: Zero physical touch, zero anesthesia drops required.
  • ✔ Ultra Low-Cost: Runs on standard consumer cameras/smartphones.
  • ✔ Local Offline Execution: Zero cloud dependency, faster inference, 100% patient data privacy.
  • ✔ Rural Healthcare Scalability: Empowers community healthcare workers with zero clinical training.

❓ Anticipated Judge Questions & Answers

Q1: Why rely on iris and pupil measurements for IOP estimation? ▼
Research shows that elevated intraocular pressure and glaucoma progression trigger subtle autonomic nervous system variations and structural changes in pupil-to-iris ratios, circularity, and pupillary light responses. We leverage these non-contact optical markers as screening risk indicators rather than direct mechanical pressure measurements.
Q2: How far have you implemented the prototype? ▼
We have built a fully functional end-to-end prototype comprising OpenCV image preprocessing (CLAHE, Gaussian filtering), precise Hough Circle boundary segmentation, 6 biometric feature extractions, Random Forest ML model training, and a real-time web dashboard.
Q3: Why use Machine Learning over static threshold rules? ▼
The biophysical relationship between pupil circularity, iris ratios, lighting conditions, and IOP is non-linear and complex. Machine learning algorithms (Random Forest) effectively model multi-variable interactions that rigid rule-based systems miss.
Q4: Why run the model locally instead of using a cloud API? ▼
Local execution ensures instantaneous latency (< 200ms), 100% patient data privacy compliance (HIPAA/GDPR alignment), zero internet dependency in remote rural medical camps, and zero operational API costs.

🗺️ Complete System Architecture & Pipeline Flow

Detailed human-understandable flowchart mapping models, tools, and datasets utilized at every processing stage:

1
Eye Image / Video Frame Capture

Captures high-resolution macro eye frame via webcam stream or user file upload.

Tool: HTML5 MediaDevices API Format: RGB Matrix / JPEG
↓
2
Preprocessing & Noise Filtering

Applies grayscale conversion, CLAHE adaptive contrast enhancement, and Gaussian blur.

Tool: OpenCV (cv2) Algorithm: CLAHE + Gaussian Filter
↓
3
Iris & Pupil Segmentation

Detects inner pupil boundary and outer iris boundary using contour fitting and Hough Circle transforms.

Tool: OpenCV Hough Transform Algorithm: Canny Edge + Morphological Ellipse Fitting
↓
4
Mathematical Feature Extraction

Computes pupil diameter, iris diameter, pupil-to-iris ratio, circularity index, symmetry, and reflectance.

Tool: NumPy & SciPy Metrics: D_p, D_i, D_p/D_i, Circularity, Symmetry
↓
5
Machine Learning Classification & Regressor

Passes normalized biometric feature vectors into Random Forest models to evaluate glaucoma risk tier and estimate IOP mmHg.

Tool: Scikit-Learn Model: Random Forest Classifier & Regressor Datasets: RIGA, DRISHTI-GS, ORIGA, REFUGE
↓
6
Interactive UI Dashboard Presentation

Displays annotated diagnostic image overlays, risk gauges, confidence scores, and clinical recommendations.

Tool: Flask + HTML5/CSS3/JavaScript Outputs: Risk Badge, IOP Range, Telemetry HUD
